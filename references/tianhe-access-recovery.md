# 天河接入与监控故障判断

- VPN 或 SSH TCP 不通：只说明当前链路不可用；检查用户的 aTrust 登录与目标可达性，不凭此判断账户密码错误。
- 主机指纹变化：在发送凭据前停止，重新通过可信渠道确认；不使用关闭校验或自动接受新指纹的选项。
- 明确认证拒绝、解密失败或认证结果未知：停止自动重试，核对当前账号与授权的凭据来源。
- AuthenticationBusy：本机有另一连接处于认证互斥区，未发送密码；有界等待后根据具体策略再试一次，不当作认证拒绝。
- 监控心跳失联：可能是观察进程、网络或通知服务的问题，不等于远程计算中断。检查真实调度状态、JobID、工作目录和最后一个真实采样时间；不要补造心跳或百分比。
- 未收到提交回执：先只读回查调度器及工作目录，确认是否存在相同任务；不能直接重复 yhbatch。
- 调度器显示 COMPLETED：仍需核验作业退出码及逐样本计算和科学结果。squeue 查不到终态时可按站点提供的 sacct 或等价历史记录核实。

scripts/tianhe_access_diagnose.py 提供只读、有限时的网络与诊断报告摘要。实时网络探测必须指定已固定的个人 profile；门户探测只在用户额外提供不含凭据或查询参数的 HTTPS 地址时执行。工具不修改代理、VPN、DNS 或其他软件。

观察器恢复仅适用于用户明确授权、固定 JobID/工作目录、原截止时间内的只读巡检；验证来源文件和互斥锁后恢复，不能以监控恢复代替科学续跑授权。
